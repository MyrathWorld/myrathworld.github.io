# Myrath — Contos dos Guardiões

Site literário oficial de Myrath, mantido pela organização MyrathWorld.

## Conteúdo

Os capítulos ficam em `src/content/books/`. Cada arquivo Markdown gera automaticamente uma página de leitura, uma entrada na biblioteca e a navegação entre capítulos.

## Publicação

O fluxo em `.github/workflows/deploy.yml` compila e publica o site no GitHub Pages após cada alteração na branch `main`.
